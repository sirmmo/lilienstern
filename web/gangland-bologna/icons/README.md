# Gangland's icons

These icons are **not** covered by Lilienstern's GPL licence. They come from a commercial
painted pack bought through Humble Bundle, *Character Portraits: Modern*, and are used here,
shrunk to 64 px, only as part of the Gangland game, as the pack's licence allows. Do not take
them for other projects: get the pack instead. (The page also uses some of Marches' icons; see
the README in web/marches/icons.)

| Icon | Stands for |
|---|---|
| gangland-soldiers | street soldiers |
| gangland-shooters | shooters |
| gangland-enforcers | enforcers |
| gangland-riders | scooter riders |
| gangland-hitmen | hitmen |
| crew | a gang's crew |
